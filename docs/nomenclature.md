# Nomenclature

The following section is meant as an help to understand the files generated by the pipeline, even if you have no will of digging through the codebase.

## Output files

This behaviour is handled by the `filename`/`savepath` methods of the `OutputFiles` enum of the `utils_enum.py` module, [see here](reference/src/seiche/utils_enum.md#src.seiche.utils_enum.OutputFiles). The following nomenclature is very far from perfect, and could benefit from some renaming.

| file name                     | description |
|------------------------------:|-------------|
| dem_\*.tif                    | The Digital Elevation Model (DEM) used for the study. |
| max_speed_\*.tif               | Single band GeoTiff raster holding the interpolated maximum water speed for the event (only relevant for .slf files). These files' information are copied in there respective band of the hzd_\*.tif files. |
| duration_\*.tif               | Single band GeoTiff raster holding the interpolated flood duration for the event. These files' information are copied in there respective band of the hzd_\*.tif files. |
| hzd_\*.tif                    | 3-band water hazard GeoTiff raster, where the 3 bands are (**in this order**): H(x, y), the field of the maximum water depth during the event; V(x, y), the field of the maximum water speed during the event; and T(x, y) the field of the flood duration for this event. For HZD based on slf files, the `_from_freesurf` suffix indicates that the maximum depth was computed as the difference between the simulated free surface and the DEM, rather than directly interpolated from the model. |
| lcv_\*.gpkg, lcv_\*.tif       | Vector (.gpkg) and Raster (.tif) landcovers used for the study. |
| dmgfac_\*.gpkg, dmgfac_\*.tif | Vector (.gpkg) and Raster (.tif) - depending on which landcover was used - damage factor for the JRC damage functions. The final damage is the product `dmgfac * maxdmg`. |
| maxdmg_\*.gpkg, maxdmg_\*.tif | Vector (.gpkg) and Raster (.tif) - depending on which landcover was used - maximum damage (vulnerability) for the JRC damage functions. The final damage is the product `dmgfac * maxdmg`. |
| std_\*.gpkg, std_\*.tif       | Vector (.gpkg) and Raster (.tif) - depending on which landcover was used - standard deviation for the JRC damage functions. It is often empty depending on the considered region. |
| dmg_\*.gpkg, dmg_\*.tif       | Vector (.gpkg) and Raster (.tif) - depending on which landcover was used - estimated damage by the Floodam damage functions. |
| ghslpop_\*.tif                | GHSL-POP population rasters, where the pixels kept correpond to the conditions applied to a specific water hazard (see full file name). |
| filosofi_\*.gpkg              | Filosofi population pseudo-rasters, where the pixels kept correpond to the conditions applied to a specific water hazard (see full file name). |
| \*.png                        | Each of the previously mentioned files can be automatically plotted for a quick assessment of the code outputs, in this case the plot name is just `filename + ".png"` |
